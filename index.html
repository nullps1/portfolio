01Selected work

Three public projects, described from their repositories. Each links to the source.

  1. NullBrain / NullCode

    A software-development workflow that runs entirely on a Raspberry Pi with local models. It takes a task, generates Java with a local Ollama model, compiles and tests the result in a locked-down container, attempts a bounded number of repairs, and prepares a draft pull request only when a human asks it to.

    • Inference stays on the host; nothing leaves it except the explicit publish step.
    • Candidate code is built and tested in Docker containers with no network access.
    • A review gate can refuse a commit, and a human grants the edit scope and triggers publishing.
    Stack
    Python (standard library only), Rust (Axum), SQLite, Docker, Ollama
    Status
    Working pipeline, version 0.1.0
    Source
    github.com/nullps1/nullbrain

  2. Arcane Extraction

    A Minecraft mod for NeoForge 1.21.1 that adds a workstation block. It moves one chosen enchantment from an enchanted item onto a book and keeps the exact level. The extraction rules are kept apart from the block and menu code, and the server decides whether a request is valid.

    • The client sends only an enchantment ID. The server re-checks the open menu, the player’s distance and the item’s real enchantments before changing anything.
    • 25 JUnit tests cover the extraction rules, the inventory transaction, hopper automation and the block model. Multiplayer behaviour was checked by hand; there are no automated in-game tests.
    • Version 1.0.1 fixed a crash with Quark’s Ancient Tomes, caused by removing a default item component instead of resetting it.
    Stack
    Java 21, NeoForge, JUnit 5, Gradle, GitHub Actions
    Status
    Released, v1.0.1 · MIT license
    Source
    github.com/nullps1/Arcane-Extractor

  3. NullScan

    A TCP port scanner written in Rust. It scans hosts and CIDR ranges concurrently, reads service banners with protocol-specific probes, and exports JSON, CSV, Markdown or HTML reports. An optional dashboard serves the results locally.

    • Asynchronous scanning on Tokio with configurable concurrency and timeouts, and an optional TCP-based ping sweep that skips hosts that do not answer.
    • The optional vulnerability check matches banners against a bundled list of CVE records by string, with no version-range comparison, so treat its output as leads to verify.
    • Linux and Windows binaries are published with SHA-256 checksums, and CI runs on Linux, Windows and macOS. Use it only on networks you are authorized to test.
    Stack
    Rust, Tokio, Clap, Serde, Axum
    Status
    Released, v1.6.0 · MIT license
    Source
    github.com/nullps1/nullscan

03About

Weeks IT Solutions is Noah’s software and technology practice. The work is small, practical tools and the systems that keep them running: software that does one job, says what it does and does not do, and can be operated by someone other than its author.

  • Bounded by design

    Automation gets explicit limits. NullCode caps its repair attempts and never publishes without a human command.

  • Operable

    Services run in containers with health checks, so a failure is visible and a bad release can be reverted.

  • Honest scope

    Documentation states what a tool does not do as clearly as what it does.

My background includes surveying and construction technology. That practical field experience shapes how I build: tools that turn raw field data into something usable and checkable.
