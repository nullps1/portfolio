01Selected work

Three public projects, described from their repositories. Each links to the source.

  1. NullBrain / NullCode

    A software-development agent that runs entirely on a Raspberry Pi with local models. It takes a task, generates Java with a local Ollama model, compiles and tests the result in a locked-down container, attempts a bounded number of repairs, and prepares a draft pull request only when a human asks it to.

    • Inference stays on the host; nothing leaves it except the explicit publish step.
    • Candidate code is built and tested in Docker containers with no network access.
    • A review gate can refuse a commit, and a human grants the edit scope and triggers publishing.
    Stack
    Python, Rust (Axum), SQLite, Docker, Ollama
    Status
    In active development
    Source
    github.com/nullps1/nullbrain

  2. NullScan

    A cross-platform TCP port scanner written in Rust. It scans hosts and CIDR ranges concurrently, identifies services from banners with a confidence score, checks results against an offline vulnerability database, and exports JSON, CSV, Markdown or HTML reports.

    • Asynchronous scanning on Tokio with configurable concurrency and an optional ping sweep.
    • Prebuilt binaries are published on GitHub Releases, and the repository runs CI.
    • Use it only on networks you are authorized to test.
    Stack
    Rust, Tokio, Clap, Serde
    Status
    Released, v1.6.0 · MIT license
    Source
    github.com/nullps1/nullscan

  3. Copperworks

    A Minecraft mod for NeoForge 1.21.1 that adds copper tools and armor which oxidize over time. Equipment moves through four stages, changing its durability wear, mining speed, damage and defense. Players can wax a piece to freeze its stage or scrape it back with an axe.

    • Oxidation is probabilistic and faster in water and rain, so it behaves like weathering, not a timer.
    • Balance values are configurable on the server.
    • Requires Java 21; multiplayer needs the same version on the server and every client.
    Stack
    Java 21, NeoForge
    Status
    Released, v1.0.0
    Source
    github.com/nullps1/copperworks

03About

Weeks IT Solutions is Noah’s software and technology practice. The work is small, practical tools and the systems that keep them running: software that does one job, says what it does and does not do, and can be operated by someone other than its author.

  • Bounded by design

    Automation gets explicit limits. NullCode caps its repair attempts and never publishes without a human command.

  • Operable

    Services run in containers with health checks, so a failure is visible and a bad release can be reverted.

  • Honest scope

    Documentation states what a tool does not do as clearly as what it does.

My background includes surveying and construction technology. That practical field experience shapes how I build: tools that turn raw field data into something usable and checkable.
